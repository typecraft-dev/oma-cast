LaunchAnything.Instantly.

omacast is a Raycast-style launcher that runs inside Omarchy. It learns what you use, searches your apps and every Omarchy action, does the math, keeps your clipboard, and wears your theme.

Install omacast

Then press Alt + Space. Super + Space stays the Omarchy menu.

This is omacast itself, running in your browser.

Not a port. A plugin.

omacast runs inside omarchy-shell, the shell that draws Omarchy's own bar and menus. No Electron, no Node, no daemons, no extra packages.

Learns your habits

Results are ranked by a faithful port of Raycast's root-search algorithm, plus frecency and learned search terms. Type ff, pick Firefox, and ff keeps meaning Firefox.

One search for everything

Your apps, all ~400 Omarchy menu actions with breadcrumbs and live ✓ state, the calculator, and web-search fallbacks, in one ranked list.

Opens in one frame

The hotkey goes straight to the plugin with no process to start, and the window stays ready while hidden, so opening it is a single redraw.

Wears your theme

There's no theme config. omacast uses Omarchy's own colours and changes the moment you run omarchy theme set. Under Glassy Windows it turns see-through and blurred, like the rest of Omarchy.

Finds your open window

↵ on an app jumps to its open window, switching workspace and restoring it from the dock. It even recognises web apps. Shift ↵ opens a new one.

Private by default

No account, no telemetry, never contacts Raycast. Histories live in owner-only files, and nothing you type ends up on a command line. The one network request, exchange rates, can be turned off.

Forgives typos

An optional search helper, built on your machine from source, matches titles, alternate names and keywords even with transposed or missing letters.

Keyboard-first

A Ctrl K action panel on every result, quick picks, section jumps, search history, and emacs or vim-style movement. The mouse is optional.

Make it yours

Give anything an alias, pin and reorder favorites, hide commands you never use, and switch to a compact window that shows only the search bar until you type.

The stuff you reach for daily.

Each one is a search away, and the big ones get their own hotkey through a Hyprland global shortcut.

Clipboard History

Everything you copy (text, links, colours, files and images), with the app it came from and how often you copied it.

  • List and preview side by side, filtered by type on Ctrl P
  • Paste back into any app, terminals included
  • Pin entries, pick how long to keep the rest
  • Password managers and anything marked sensitive are never recorded
omacast:clipboard

Emoji & Symbols

An 8-column grid of every Unicode 17 emoji, searchable by name and by Omarchy's emoji keywords.

  • Pinned and Recently Used up top
  • Skin tones from the action panel
  • ↵ pastes, Ctrl ↵ copies, arrows move around the grid
omacast:emoji

Switch Theme

All your Omarchy themes with a preview of each beside the list. ↵ applies it, and omacast changes with it.

  • Opens on your current theme
  • Replaces Omarchy's theme picker in the results
omacast:theme

Calculator & History

Type math, units, currencies, dates or time zones straight into the search bar. Every answer you copy or paste is saved to a searchable history.

The whole Omarchy menu

Every Omarchy menu action is searchable from the root, with breadcrumbs like Appearance › Windows. Submenus open in place, live state shows as ✓, and hidden items stay hidden.

Web search fallbacks

No match? Send the query to Google or DuckDuckGo. Both also take a query in an argument pill: Tab into it and type.

Just type the question.

A calculator built into the search bar, with its own engine and no extra dependencies. Answers show above the results as you type.

  • Math: arithmetic, powers, roots, trig and more
  • Percentages: $30 + 20%, 20% off 50, 50 as a % of 200
  • Units: about 250 of them, mixed units like 5 ft 3 in, and CSS px / rem
  • Currencies: daily ECB rates, cached for the day
  • Dates and time zones: 3 days from now, days until christmas, 3pm london to nyc
  • Number bases, work time and Unix time

↵ copies the answer, Ctrl ↵ pastes it, Ctrl Shift C copies “question = answer”.

Plain files. A real CLI.

Preferences live in a JSON file that applies the moment you save it, and the omacast CLI does the rest, including a doctor that tells you what's wrong.

~/.config/omacast/config.json
{
  "currencyRates": true,          // the only network request
  "clockFormat": "auto",          // or "12h" / "24h"
  "remToPxRate": 16,
  "workHoursPerDay": 8,
  "rootFilter": true,
  "keepVisibleOnFocusLoss": false,
  "clipboardHistory": true,
  "clipboardHistoryDuration": "P1W"
}

Four commands. That's it.

Needs Omarchy 4 (Hyprland 0.56+). omacast uses only what Omarchy already ships: no new packages, no background services. It's also on the Omarchy plugin marketplace.

Add the plugin

omarchy plugin add https://github.com/typecraft-dev/oma-cast --enable

Link the CLI

~/.config/omarchy/plugins/typecraft.omacast/bin/omacast install

Bind the hotkey

Shows what it will change and asks first. It never edits Omarchy's own files.

omacast setup hyprland

Check everything is wired up

omacast doctor

Update with omarchy plugin update typecraft.omacast. Remove with omacast uninstall; your data stays until you delete it.
